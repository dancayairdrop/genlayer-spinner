GenLayer Portal Spinner

A single-file, dependency-free loading spinner for the GenLayer Portal. Pure SVG + CSS animation (no JS required to run), themeable via currentColor, accessible (role="status"), and prefers-reduced-motion aware. This page is the live deployment — every spinner below is the exact deliverable (genlayer-spinner.svg) running in your browser.

On light background — Kinetic Cobalt #110FFF

On dark background — lighter tint #4C6FFF for AA legibility

Full-page loading state (typical Portal usage)

Usage

<!-- As an image (static loading pages) -->
<img src="genlayer-spinner.svg" width="32" height="32" alt="Loading">

<!-- Inlined in a React/JSX component (lets you theme per context) -->
<span style={{ color: '#110FFF' }} dangerouslySetInnerHTML={{ __html: spinnerSvg }} />
